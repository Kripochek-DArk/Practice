# Лабораторная №8

## Задача 1

### Текст задачи
Разработать консольное приложение с дружественным интерфейсом с возможностью выбора
заданий для работы с «базой данных (БД)», хранящейся в бинарном файле. Перечень полей
(минимум 5), достаточно полно характеризующих заданную в варианте предметную область,
предложить самостоятельно (постараться отразить в перечне полей такие, которые требуют разных
типов данных). Приложение должно выполнять следующие функции:
1. Чтение базы данных из бинарного файла.
2. Просмотр базы данных.
3. Удаление элементов (по ключу).
4. Добавление элементов.
5. Реализация 4 запросов (формулировки запросов придумать самостоятельно). 2 запроса
должны возвращать перечень, 2 запроса одно значение.
В классе должны присутствовать свойства, конструкторы, перегруженный метод ToString(). Весь
функционал приложения реализовать в виде методов вспомогательного класса с помощью LINQзапросов.
Предусмотреть обработку возможных ошибок при работе программы

## Алгоритм решения

- Создан класс Test для представления записи базы данных

- Реализована работа с бинарным файлом:

  - запись данных через BinaryWriter
  - чтение данных через BinaryReader

- Реализованы методы работы с базой данных:

  - просмотр записей
  - добавление записей
  - удаление записей по ID

- Реализованы LINQ-запросы:

  - поиск тестов по предмету
  - поиск тестов с уровнем сложности выше заданного
  - вычисление среднего количества вопросов
  - подсчёт количества доступных тестов

- Реализована сортировка результатов через OrderByDescending

- Реализована фильтрация данных через Where

- Реализованы проверки существования элементов через Any

- Реализован поиск элементов через FirstOrDefault

- Реализовано вычисление среднего значения через Average

- Реализован подсчёт элементов через Count

- Создан класс Program

- Реализовано консольное меню приложения

- Реализован ввод данных пользователем:

  - целых чисел
  - вещественных чисел
  - строк
  - логических значений

- Организована проверка корректности ввода:

  - диапазона чисел
  - пустых строк
  - корректности логических значений

- Реализована обработка исключений:

  - IOException
  - Exception

- Реализован вывод результатов работы программы в консоль
