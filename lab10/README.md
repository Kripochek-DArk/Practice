# Лабораторная №10

## Задача 1

### Текст задачи

1. Опишите функцию nextch — модуль ввода-вывода. (Примечание: из-за отсутствия
анализатора, формирующего таблицу ошибок, создайте таблицу ошибок вручную.)
2. Разработайте набор тестов для тестирования модуля ввода-вывода.
3. Выполните тестирование модуля ввода-вывода

### Алгоритм решения

- Разработана структура TextPosition с полями для хранения текущего номера строки и номера символа в тексте.

- Реализована структура Err, связывающая координату ошибки с её числовым кодом.

- Создан модуль ввода-вывода InputOutput с посимвольным буферизированным чтением исходного файла.

- Разработан метод NextCh(), осуществляющий последовательный сдвиг по символам строки и автоматический переход на новую строку при достижении её конца.

- Вручную сформирована таблица кодов ошибок для их последующей визуализации.

- Внедрен метод ListErrors(), вычисляющий точный графический отступ и выводящий маркер ошибки ^ строго под косячным символом.

- Реализована симуляция работы синтаксического анализатора в главном цикле программы на базе генератора случайных чисел Random.

- Задан фиксированный процентный шанс (5%) для генерации случайного кода ошибки на каждом обрабатываемом символе.

- Проведено комплексное тестирование модуля на тестовом коде языка Pascal с автоматической записью, чтением и последующим удалением временного файла с диска.
